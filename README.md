# 🎬 BingePlay – MySQL Database Project

BingePlay is a **MySQL database project** designed to manage and analyze data for a streaming platform.

## 📌 Project Overview

The database contains information about:

* Users
* Subscriptions
* Shows
* Watch Sessions
* Ratings

## 🛠️ Technologies Used

* MySQL
* MySQL Workbench
* SQL

## 📊 Database

**Database Name:** `bingeplay`

Main tables:

* `users`
* `subscriptions`
* `shows`
* `watch_sessions`
* `ratings`

## 🎯 Project Objectives

* Analyze user subscriptions and revenue
* Study watching patterns
* Analyze show ratings and popularity
* Perform SQL-based data analysis
* Generate useful insights using queries
